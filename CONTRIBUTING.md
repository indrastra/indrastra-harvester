# Contributing

Thank you for considering a contribution to IndraStra Harvester.

## Development principles

- Keep changes focused and testable.
- Preserve source metadata and provenance.
- Treat repository endpoints and XML payloads as untrusted input.
- Do not introduce destructive record merges.
- Document protocol and schema changes.
- Add tests for bug fixes and new behavior.

## Workflow

1. Open or select an issue.
2. Create a feature branch.
3. Add or update tests.
4. Run formatting, linting, and tests.
5. Submit a pull request describing the change and its compatibility impact.

## Security issues

Do not report exploitable vulnerabilities in public issues. Follow SECURITY.md.
